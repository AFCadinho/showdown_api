Pokemon Info

Geeft bevestigde battle-info terug voor een Pokemon vanuit het perspectief van een speler.

Endpoint

GET /battles/:battleId/pokemon-info Query parameters required

Gebruik deze route voor hover-cards of UI-panelen die alleen bekende moves, PP, item en ability mogen tonen.

Path Parameter

De battle id komt uit de response van /create_battle of /create_wild_battle.

Query Parameters

De API kijkt vanuit de opgegeven viewer. Daardoor wordt tegenstander-info alleen teruggegeven als die in deze battle al bekend is geworden.

Request Voorbeeld

Wat Krijg Je Terug?

Bij bekende info krijg je een Pokemon object terug. Als de viewer nog niets mag weten, is pokemon null.

Succes Response

Onbekend Voor Viewer

Error Response

Als de battle id, viewerId of ident niet klopt, krijg je een foutmelding terug.
